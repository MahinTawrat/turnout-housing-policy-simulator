# Data provenance

This record covers the sources used to reconstruct the simulator's [official release](../data/release/release.json). The [portable CSV](data-provenance.csv) supplies one row per acquired file or service extract, including the exact URL, source edition, access date, terms, cleaning steps, limitations and SHA-256. It provides the fields requested in the [Challenge Handbook](https://housingchallenge.turnout.rocks/handbook.html) for transfer into the platform's Data Provenance template.

The acquisition manifest records 117 items verified on **2026-11-18**, including 2 archived map files. The CSV records the access date and fingerprint for each item. It includes metadata only. The rebuild fetches raw files from the sources in the [acquisition catalog](../config/sources.json) and retains them in a local ignored cache. Run `python scripts/acquire.py --group all` to acquire and verify sources or `python scripts/refresh.py` for the full reconstruction. The [rebuild guide](../README.md#rebuild-from-official-data) describes the spatial dependencies and update process.

## Permits and independent estimates

All rows in the following tables were accessed on **2026-11-18**. Census and HUD sources are public agency products. Retain source attribution and agency notices. California and North Carolina projections are published state agency statistical products with no dataset-specific license specified in the acquisition catalog. The software's Apache-2.0 license covers first-party code. See the [Census public-use and citation statement](https://www.census.gov/about/policies/citation.html) and [project notices](../NOTICE).

## American Community Survey

These 18 detailed tables share the **2020–2024 five-year** vintage, **2026-11-18** access date, and Census public-use terms with attribution retained. The links go directly to the acquired files. For all tables, the rebuild retains relevant estimate and margin cells, matches supported geographic identifiers and treats suppressed or special negative cells as missing. Small-area sampling variation and missing cells can limit conclusions. A derived margin that combines cells omits covariance. See [ACS methodology](https://www.census.gov/programs-surveys/acs/methodology.html).

The [transit reconstruction manifest](../data/release/spatial/spatial_manifest.json) records the tract, ACS and stop input hashes, projection and weighting method, and suppressed tracts. The [display boundaries manifest](../data/release/spatial/display_boundaries_manifest.json) separately identifies the browser map inputs. The [frozen snapshot](../data/snapshot/) remains available for comparison with the earlier approved outputs. Its inherited spatial extraction trail is incomplete. The official reconstruction uses the documented source data and method above and can produce different transit estimates or map shapes.

Only published aggregate tables and public geography enter the model. The evidence flags small or imprecise survey cells and preserves official suppression. The full build distributes compact processed inputs and leaves original files in the local acquisition cache. See [data and reconstruction](DATA.md) for detailed limitations.
